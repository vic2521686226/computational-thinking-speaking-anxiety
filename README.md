# Computational Thinking: Speaking Anxiety

A simple, self-contained HTML, CSS, and JavaScript prototype exploring four sources of classroom speaking anxiety through interaction.

## Run locally

Open `index.html` in a modern web browser. No build step, dependencies, or external services are required.

## Interactions

Adjust the four sliders to explore how the scene responds:

- Peer anxiety adds watching eyes around the speaker.
- Language anxiety widens the spacing between words.
- Reasoning anxiety makes the thought slightly unsteady.
- Content anxiety fades the speaking prompt.

The levels are visual representations for reflection, not diagnoses.
